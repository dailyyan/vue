## 꾸준함 기록지

오늘 컨디션을 기준으로 운동 또는 학습 계획을 작게 만드는 기록지입니다.

- 이름을 입력하면 같은 브라우저에 저장된 해당 이름의 과거 기록이 전부 표시됩니다.
- 몸 에너지, 마음 여유, 시간, 부담감을 기준으로 오늘 할 계획 개수를 자동 추천합니다.
- 아주 힘든 날에도 최소 1개는 할 수 있게 계획을 줄여줍니다.
- 완료 체크, 이력 저장, JSON 내보내기, 연속 기록 확인을 지원합니다.
- 완료량에 따라 포인트를 획득하고, 누적 포인트로 아바타 복장, 장식, 배경, 배지를 꾸밀 수 있습니다.

사용 파일:

- `index.html`: 메인 실행 파일
- `consistency-planner.html`: 같은 앱의 명시 파일

기록 데이터와 아바타 설정은 브라우저의 `localStorage`에 저장됩니다. 같은 기기와 같은 브라우저에서는 이름을 다시 입력하면 과거 이력이 보입니다. 다른 기기나 다른 브라우저와 자동 동기화되지는 않습니다.

## 일일 기분 체크

조울증 관련 기분 상태를 매일 기록하고, 결과와 솔루션을 확인하는 기록지입니다.

- 이름을 입력하고 문항을 체크하면 결과가 `localStorage`에 저장됩니다.
- 이력과 흐름은 기록할 때 입력한 이름을 정확히 입력해야 조회됩니다.
- JSON 내보내기와 삭제도 조회한 이름의 기록에만 적용됩니다.
