## 꾸준함 기록지

오늘 컨디션을 기준으로 운동 또는 학습 계획을 작게 만드는 기록지입니다.

- 이름을 입력하면 같은 브라우저에 저장된 해당 이름의 과거 기록이 전부 표시됩니다.
- 몸 에너지, 마음 여유, 시간, 부담감을 기준으로 오늘 할 계획 개수를 자동 추천합니다.
- 아주 힘든 날에도 최소 1개는 할 수 있게 계획을 줄여줍니다.
- 완료 체크, 이력 저장, JSON 내보내기, 연속 기록 확인을 지원합니다.
- 완료량에 따라 포인트를 획득하고, 누적 포인트로 아바타 복장, 장식, 배경, 배지를 꾸밀 수 있습니다.

사용 파일:

- `index.html`: 메인 실행 파일
- `consistency-planner.html`: 같은 앱의 명시 파일

기록 데이터와 아바타 설정은 브라우저의 `localStorage`에 저장됩니다. 같은 기기와 같은 브라우저에서는 이름을 다시 입력하면 과거 이력이 보입니다. 다른 기기나 다른 브라우저와 자동 동기화되지는 않습니다.

## 일일 기분 체크

조울증 관련 기분 상태를 매일 기록하고, 결과와 솔루션을 확인하는 기록지입니다.

- 이름을 입력하고 문항을 체크하면 결과가 `localStorage`에 저장됩니다.
- 이력과 흐름은 기록할 때 입력한 이름을 정확히 입력해야 조회됩니다.
- JSON 내보내기와 삭제도 조회한 이름의 기록에만 적용됩니다.

## 개발 진척 포털 (시제품)

고객사 담당자가 접속키로 들어와 자기 회사 프로젝트의 진척도를 확인하는 사이트의 시제품입니다. 구축 계획서의 기능 정의·상태 단계·접속키 규칙을 그대로 따릅니다.

- 파일: `progress-portal.html` (Vue 3, CDN으로 불러옴, 빌드 없음)
- 상태 5단계와 진척 가중치: 대기 0 · 개발중 30 · 내부테스트 60 · 고객검수 80 · 완료 100 (공수 가중 평균)
- `완료`는 고객의 [확인]으로만 바뀝니다. 확인·반려·서명은 이메일 인증번호를 한 번 더 받습니다 (시제품은 화면에 표시).
- 고객 화면: 대시보드(진척률·완료율·확인 요청·주간 추이), WBS(간트), 기능 목록·상세, 확인서 서명
- 관리자 화면: 전체 현황, 기능 상태(GitHub 라벨 변경 흉내), 기능 구현 확인서·인수 확인서 발행, 접속키 발급·폐기
- 로그인 화면의 시연용 접속키를 누르면 역할별로 바로 들어갈 수 있습니다.
- 모든 데이터는 예시이며 기준일은 2026-11-18로 고정했습니다. 처리 내용은 브라우저 `localStorage`에만 저장되고, 화면의 [시연 데이터 초기화]로 되돌립니다.

시연 순서 예시: 이수진(가나상사 담당자)으로 ORD-002 확인 → 최민아(다라물산 담당자)로 INT-002 확인 → 관리자로 `데이터 연동` 기능 구현 확인서 발행 → 오준석(다라물산 책임자)으로 서명.

실제 서비스로 만들 때는 GitHub 연동, 접속키 검사, 상태 이력 저장을 서버로 옮겨야 합니다 (계획서 2장·5장).
